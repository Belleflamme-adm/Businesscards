      Comment l'installer
      1. Outlook Web / nouvel Outlook : clique « Copier la signature », puis Paramètres › Comptes › Signatures › Nouvelle signature, et colle (Ctrl+V). Choisis-la par défaut pour les nouveaux messages et les réponses.
      2. Outlook classique (Windows) : clique « Télécharger », puis place le fichier .htm dans %APPDATA%\Microsoft\Signatures. Redémarre Outlook et choisis-la dans Fichier › Options › Courrier › Signatures.
      3. Cellulaire : l'app Outlook mobile n'accepte que du texte. Utilise une version courte : nom, titre, cel.
